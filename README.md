📊 Inventory Sales Management – Power BI Dashboard
📌 Overview

This project is a Power BI dashboard built to analyze and manage inventory and sales performance.
It provides actionable insights for businesses to track stock, monitor sales, and optimize operations.

🔑 Features

📦 Inventory Tracking – Monitor stock levels and movements

💰 Sales Analysis – Understand revenue trends and product performance

📉 Inventory vs. Sales – Compare on-hand stock against sold items

📊 KPIs & Metrics – Key measures for data-driven decision making

🛠️ Requirements

Power BI Desktop

Dataset used: Inventory sales data (.xlsx)

📂 Project Files

Inventory sales management.pbix – Power BI dashboard file

🚀 How to Use

Clone this repository

git clone https://github.com/Rajeshm03/inventory-sales-management.git


Open the .pbix file in Power BI Desktop

Refresh the data source (if required)

Explore the interactive dashboard
